# Course-wide terms (settled 25 September 2026)

Use these the same way in every lesson, deck, and speaking note.

- **Course example**, not "canonical", in anything a learner reads or hears. ("The course example's base case", "from the course example file".)
- **ADR** is "average nightly rate (ADR)" on first use.
- **The $10,000 buffer**: the cash Maya and Chris keep unallocated after signing, introduced in PA.8.3 and applied in PA.8.6. Call it "buffer", not "floor", and point to PA.8.3.
- **Pass rule** means only PA.1's walk-away rule: pass on a listing that fails it. OP.11's tests for buying property #2 are "go tests" (all must pass to go).
- **Weak case** (not "stress case") for Cedar Ridge; **stress case** for Alder Street, as each example file names them.
- **Maya and Chris** use "they/them". The Alder Street operator is "you".
- Cedar Ridge's post-diligence base cash flow is **$5,172** and weak case **-$5,875** (PA.9 added a $400 yearly permit renewal). Lessons that show the original $5,572 / -$5,475 must say they're pre-diligence figures.
